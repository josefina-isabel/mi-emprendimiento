# Tecnologías del proyecto — El Sauce Huevitos

> Guía: [Tecnologías del proyecto](../evaluacion/guias/fase-1-requerimientos/04-tecnologias.md)

## Stack

| Área | Herramienta | Para qué la uso |
|---|---|---|
| Construcción | HTML + CSS | Para crear la estructura, contenido y diseño visual de la página web. |
| Versionado | Git y GitHub | Para guardar, organizar y controlar los cambios realizados en el proyecto. |
| Publicación | GitHub Pages | Para publicar la página web y permitir que pueda ser visitada mediante Internet. |
| Diseño | Whimsical | Para organizar y representar ideas, estructuras y elementos del proyecto. |
| Diseño | Google Stitch | Para crear y visualizar propuestas de diseño e interfaces para el sitio web. |
| IA | ChatGPT | Para apoyar la generación de ideas, contenidos y soluciones para el desarrollo del proyecto. |
| Editor | Visual Studio Code | Para escribir y editar el código HTML y CSS de la página web. |

## Integraciones para una versión real

- Integración con WhatsApp Business para recibir y gestionar pedidos.
- Sistema de pagos online para permitir compras directamente desde el sitio.
- Base de datos para almacenar productos, clientes y pedidos.
- Sistema de gestión de inventario para actualizar automáticamente la disponibilidad de productos.
- Integración con Instagram para mostrar contenido y facilitar el acceso a las redes sociales.

## Restricciones

- **Plazo:** 29 de septiembre al 14 de octubre (fechas de desarrollo y entrega del proyecto).
- **Plaza / Zona:** El sitio está orientado principalmente a clientes de la zona donde opera El Sauce Huevitos y sus alrededores.
- **Marca:** Se debe mantener la identidad visual, nombre, logo y estilo de comunicación de El Sauce Huevitos.
- **Dispositivos:** El sitio debe adaptarse principalmente a celulares, además de computadores y tablets.
