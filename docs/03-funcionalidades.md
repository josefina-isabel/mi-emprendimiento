# Objetivos del usuario y funcionalidades — El Sauce Huevitos

> Guía: [Objetivos del usuario y funcionalidades](../evaluacion/guias/fase-1-requerimientos/03-funcionalidades.md)

## Objetivos de la proto-persona en el sitio

1. Conocer los productos disponibles, sus precios y características.
2. Encontrar información útil sobre los productos y el emprendimiento.
3. Realizar un pedido y comunicarse fácilmente con El Sauce Huevitos.

## Funcionalidades

| Proto-persona | Objetivo | Funcionalidad | Tipo | Prioridad |
|---|---|---|---|---|
| Carolina | Realizar consultas o recibir información | El usuario debe poder dejar sus datos para recibir información, promociones o novedades de El Sauce Huevitos. | Base (landing) | Alta (Imprescindible) |
| Carolina | Encontrar información útil | El usuario debe poder navegar los artículos del blog por categoría, como alimentación, productos naturales y consejos. | Base (blog) | Media (Deseable) |
| Carolina | Interactuar con el contenido | El usuario debe poder comentar un artículo del blog. | Base (blog) | Baja (Futuro) |
| Carolina | Compartir información | El usuario debe poder compartir un artículo del blog en redes sociales. | Base (blog) | Media (Deseable) |
| Carolina | Encontrar productos | El usuario debe poder buscar productos por nombre o categoría. | Base (tienda) | Alta (Imprescindible) |
| Carolina | Encontrar productos específicos | El usuario debe poder filtrar productos por categoría, como huevos, frutos secos, mermeladas y otros. | Base (tienda) | Alta (Imprescindible) |
| Carolina | Conocer los productos | El usuario debe poder ver el detalle de un producto, elegir el formato y la cantidad, y agregarlo al carrito. | Base (tienda) | Alta (Imprescindible) |
| Carolina | Realizar pedidos fácilmente | El usuario debe poder enviar su pedido directamente por WhatsApp. | Propia | Alta (Imprescindible) |
| Carolina | Conocer las opciones de entrega | El usuario debe poder consultar las zonas y condiciones de despacho. | Propia | Alta (Imprescindible) |
